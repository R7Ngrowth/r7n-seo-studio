Nette, vaste opmaak voor blogs uit R7N SEO Studio.

== Beschrijving ==
Geeft je blogs een kop met afbeelding, een inhoudsopgave, actieblokken met een knop, tipblokken, uitklapbare veelgestelde vragen en schema voor Google (BlogPosting en FAQPage).

== Installatie ==
1. WordPress → Plugins → Nieuwe plugin → Plugin uploaden → kies r7n-blog.zip → Activeren.
2. Instellingen → R7N Blog: kies je kleuren en vul de links van de actieblokken in.
3. In R7N SEO Studio: Instellingen → vink "De plugin R7N Blog staat op mijn site" aan.
